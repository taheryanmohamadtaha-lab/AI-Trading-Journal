# ژورنال معاملاتی هوشمند – AI Trading Journal

## وضعیت فعلی (مرحله ۴)
- رابط فارسی راست‌چین: داشبورد، ثبت معامله، آرشیو، گزارش آماری، ورود/خروج CSV و بکاپ
- بازارها: فارکس، ارز دیجیتال، بورس ایران (ریال/تومان)
- محاسبات مالی دقیق و مستقل از هوش مصنوعی + تست خودکار

- ثبت از روی عکس: خواندن خودکار (OCR محلی) ← جدول قابل ویرایش با درصد اطمینان ← انتقال به فرم ثبت و تأیید شما
- عکس در همه‌ی مراحل معامله: قبل از ورود، هنگام ورود، حین معامله، بعد از خروج، پس از TP، پس از SL، نتیجه‌ی نهایی
- بستن معامله باز (TP / SL / دستی) با محاسبه‌ی خودکار سود و زیان و مقایسه‌ی تصویر قبل و بعد

### مربی هوشمند (مرحله ۴)
- فیلدهای رفتاری هر معامله: رعایت برنامه، وضعیت روحی، FOMO، انتقام از بازار، ورود عجولانه، خروج زودهنگام، جابه‌جایی حد ضرر، دلیل ورود، درس معامله
- تحلیل هر معامله (آفلاین): نسبت ریسک به بازده برنامه‌ریزی‌شده، خروج زود یا دیر، ضرر بیشتر از ریسک، افزایش حجم پس از ضرر
- تحلیل دوره‌ای (۷/۳۰/۹۰ روز یا همه): ۳ نقطه قوت و ۳ ضعف، الگوهای رفتاری، بهترین/ضعیف‌ترین استراتژی، ساعت و روز، مقایسه با دوره‌ی قبل، برنامه‌ی بهبود
- هر نتیجه اندازه‌ی نمونه دارد؛ زیر ۳۰ معامله «موقتی» اعلام می‌شود و گروه‌های کمتر از ۵ معامله اصلاً گزارش نمی‌شوند
- اهداف قابل اندازه‌گیری (مثلاً رعایت برنامه حداقل ۸۰٪) با سنجش خودکار پیشرفت
- **AI آنلاین (اختیاری، پیش‌فرض خاموش):** در «تنظیمات AI» کلید و مدل خودتان را بدهید (OpenAI-سازگار، Anthropic یا Ollama محلی). پیش از هر ارسال متن دقیق نمایش داده می‌شود و فقط با تأیید شما ارسال می‌شود؛ عکس‌ها و معاملات خام هرگز ارسال نمی‌شوند. AI فقط اعداد محاسبه‌شده‌ی برنامه را تفسیر می‌کند و عددهای تازه‌ی پاسخ او علامت‌گذاری می‌شود.
- کلید API در حافظه‌ی امن ویندوز ذخیره می‌شود و هرگز در GitHub قرار نمی‌گیرد.

هنوز ساخته نشده: تقویم شمسی، خروجی Excel/PDF، صفحه‌ی استراتژی‌ها و مدیریت ریسک، تحلیل بصری نمودار با مدل بینایی.

### نکته‌ی OCR
خواندن خودکار تصویر به برنامه‌ی رایگان **Tesseract** نیاز دارد (روی ویندوز: نسخه‌ی UB Mannheim را با گزینه‌های پیش‌فرض نصب کنید). بدون آن، برنامه کار می‌کند ولی خواندن خودکار تصویر خاموش است؛ می‌توانید متن را دستی بچسبانید یا اطلاعات را مستقیم در فرم وارد کنید.
عکس‌ها در پوشه‌ی `AITradingJournal\images` ذخیره می‌شوند و در فایل بکاپ پایگاه داده **نیستند**؛ برای انتقال به کامپیوتر دیگر این پوشه را هم کپی کنید.

## گرفتن فایل EXE (بدون نصب پایتون)
1. در github.com روی **New repository** بزنید و یک مخزن بسازید (مثلاً AI-Trading-Journal).
2. در صفحه‌ی مخزن، **uploading an existing file** را بزنید و *همه‌ی محتوای* پوشه‌ی زیپ را بکشید و رها کنید (پوشه‌ی `.github` هم باید باشد). بعد **Commit changes**.
3. تب **Actions** را باز کنید. «Build Windows» خودکار اجرا می‌شود (حدود ۵ تا ۱۰ دقیقه). اگر اجرا نشد: روی آن کلیک کنید ← **Run workflow**.
4. وقتی تیک سبز شد، روی اجرا کلیک کنید و پایین صفحه در بخش **Artifacts** فایل `AITradingJournal-windows` را دانلود کنید.
5. زیپ را Extract کنید و `AITradingJournal.exe` را اجرا کنید.
   (ویندوز ممکن است هشدار SmartScreen بدهد؛ «More info ← Run anyway».)

اطلاعات برنامه در پوشه‌ی `AITradingJournal` داخل پوشه‌ی کاربری شما ذخیره می‌شود. از بخش «ورود / خروج / بکاپ» مرتب بکاپ بگیرید.

## ساخت نسخه‌ی جدید
در GitHub: **Releases ← Draft a new release** ← یک Tag مثل v1.0 ← **Publish**. فایل EXE خودکار به همان Release اضافه می‌شود.
